Scope decisions, recorded before render
- (a) The envelope follows abs of the live input exciteIn through the same letrec follower shape round 2 R2c used, with attack time constant 10 ms and release time constant 100 ms (ba.tau2pole). Its output is the previous sample's state, so on the first sample of a step the gain is still unity.
- (b) exciteEnvFloor = 0.1 is the gain's lower bound: gain = floor + (1 - floor)*env when the input dial is 1, so the live path never closes. Without a floor the gain is exactly 0 on the sample of the audit's R1 impulse, because the follower lags one sample, which removes the probe excitation and leaves the decay measurement undefined. The floor bounds the excitation scale; it changes no threshold.
- (c) gain = 1 - inputAmt*(1 - floor)*(1 - min(1, env)). With the input dial at 0 the gain is exactly 1.0 on every sample and key-only output is bit-identical to shipped by construction. With env at or above 1 the gain is 1. With env at 0 the gain is the floor.
- (d) E2 shortens T60 by passing freqFund*dampShorten to modePole. modeInvT60 scales with freqFund, so T60 scales by 1/dampShorten, while freqMode, which sets the mode frequency, is computed from freqFund alone and is untouched, so pitch does not move. dampShorten = 1 + inputAmt*dampShortenMax*(1 - min(1, envRatio)) with dampShortenMax = 3.0, so the shortest ring is T60/4.
- (e) envRatio = (env + exciteEnvRatioFloor)/(envPeak + exciteEnvRatioFloor), where envPeak is a peak hold of env with a 0.5 s release and exciteEnvRatioFloor = 0.05, about half the corpus RMS level of 0.1. The shared floor makes the ratio answer the mouth quieting after it has sounded rather than an absolutely quiet input: for the audit's R1 probe, a single 0.05 impulse whose envelope is about 1e-4, the ratio stays at 1 and the decay is untouched. That is what makes R1 a meaningful criterion for E2.
- (f) Both modulations are multiplied by inputAmt, so both are inert at input dial 0. Key-only decay, and therefore every key-only render, is untouched by construction.
- (g) No loudness compensation is added. Scaling the excitation lowers the mouth-driven level; the level change is measured and reported, not corrected.
- (h) Only the mode bank is damped. objectVoice keeps the shipped decay.

Render conditions
- As in the audit (prereg.txt). K mode: input dial 0, key on voice 0 (note, gate 1, vel 1), every other dial at its DSP default. M mode: input dial 1.0, input file a vocal file, the key gated on from frame 0, 0.5 s silent pre-roll.
- Keys: every MIDI key 36 to 96 inclusive in K mode, 1.2 s held note, for every variant.
- Vocal set: the six vocal_* files of the audit, normalised to rms 0.1 by the pinned normaliser.
- M1: median Pearson r over the six vocal files, 20 ms RMS envelope (window 960 samples, the same definition for input and output), over the input active window after the pre-roll.
- M4: as the audit at key 60. (a) LTAS distance between the female and male vocal outputs; (b) LTAS distance between the female vocal output and the K-mode output of the same duration. Both in dB.
- R1: as the audit. 12 s render, M mode, key 60 held, the audit's impulse file (0.05 at 0.1 s), decays {0.05, 0.2, 1.2, 3.0, 6.0, 8.0}, Schroeder fit over -5 to -35 dB.

Criteria (audit thresholds; unchanged, and not revised after any number is seen)
E1 PASS iff all three:
  (i) M1 median r >= 0.8 on the vocal set;
  (ii) M4 (a) >= 1 dB and M4 (b) >= 1 dB, measured on E1's own renders;
  (iii) key-only regression: for every MIDI key 36 to 96, the K-mode E1 output file sha256 equals the base's.
E2 PASS iff all four:
  (i) M1 median r >= 0.8 on the vocal set;
  (ii) R1 still spans the range: rt60 at decay 0.05 <= 0.2 s and rt60 at decay 8.0 >= 6.0 s;
  (iii) M4 (a) >= 1 dB and M4 (b) >= 1 dB;
  (iv) key-only regression: for every MIDI key 36 to 96, the K-mode E2 output file sha256 equals the base's.
M1 is reported for every variant whether or not it passes. If both variants fail, the measured M1 of each is reported and the next untried mechanism is named.

Reproduction checks (base only; not criteria)
- Cents for keys 38, 44, 48, 60, 64 against diag_resonode.V2_P3_CENTS, tolerance 0.06 cents.
- Key-only cents of E1 and E2 equal to base's: implied by the bit-identity criterion and reported with it.
A mismatch is reported and changes no criterion.

Informational (not criteria)
